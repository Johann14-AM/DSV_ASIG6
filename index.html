Introducción al Desarrollo Web

El desarrollo web consiste en el proceso de diseñar y crear sitios o aplicaciones web a partir de la codificación. Esto conlleva definir su estructura, funcionalidades y detalles para brindar al usuario del sitiouna buena experiencia.
Esto también supone mantener el sitio o aplicación web al día, actualizando su contenido, corrigiendo herrores y vigilar su rendimiento y seguridad.

¿Qué es una Página Web?

Una página web es un documento escrito en lenguajes digitales como HTML, accesible desde un navegador web.
La página muestra contenido digital, como textos, imágenes, audios o videos.
Suelen formar parte de un sitio web, el cual es un conjunto organizado de páginas que trabajan bajo un dominio en común.

¿Cómo funcionan?

Las computadoras conectadas a la web se llaman clientes y servidores.

Clientes

Los clientes son dispositivos conectados a internet y el software que se encuentra disponible y permite acceder a internet en dichos dispositivos.

Servidores

Los servidores son computadoras que almacenan páginas o aplicaciones web.
Cuando un cliente quiere acceder a una página web, una copia de la página web se descarga desde el servidor en el equipo cliente y se muestra en el navegador web del usuario.


Tipos de Página Web

Las páginas web pueden variar en complejidad, desde documentos estáticos con texto plano e imágenes hasta sitios dinámicos con interacciones y eventos programados.

Estática

HTML, CSS y JavaScript básico. El servidor entrega el archivo exactamente tal como está almacenado, sin realizar ninguna consulta a bases de datos ni procesamiento intermedio. Son extremadamente rápidas y seguras, ideales para sitios institucionales que no cambian su información frecuentemente.

Dinámica

El contenido se genera en tiempo real cada vez que un usuario accede. Utilizan lenguajes de programación en el servidor (Backend) como PHP, Node.js o Python, conectados a un motor de Bases de Datos (MySQL, PostgreSQL). Permiten interactividad avanzada, paneles de usuario, comentarios y e-commerce

Diferencia entre Sitio y Aplicación Web

Es importante diferenciar los conceptos. Un sitio web informar o mostrar contenido, mientras que una aplicación web está diseñada para realizar tareas complejas y manipular datos.

Sitio Web

Tiene el objetivo de entregar información y es principalmente de lectura. Suele tener una complejidad menor y ser de acceso público.

Aplicación Web

Busca resolver problemas, ejecutar procesos o gestionar cuentas y servicios. Tiene un nivel de interactividad y complejidad mucho mayor, y suelen requerir crear una cuenta, registrarse y autenticarse.
